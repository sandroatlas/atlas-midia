# atlas-midia

Hospedagem pública de **artes finalizadas** para publicação nas redes sociais de Sandro Pinho (@sandrolpinho).

Serve apenas como área de passagem: os arquivos aqui existem para que ferramentas de agendamento (Metricool, Canva) consigam buscá-los por URL pública.

## Regra de conteúdo

**Entra:** arte finalizada que vai ao feed nos próximos dias, capa de Reels, thumbnail de YouTube.

**Nunca entra:**
- Qualquer material de paciente — foto, nome, caso clínico, termo de consentimento
- Documento, planilha, prontuário
- Material de curso antes do lançamento
